# Meter

A graphical display of a numeric value within a range.

[Open mounted Solid demo: meter/hero](/solid/components/meter)

<a id="anatomy"></a>

## Anatomy

Import the component and assemble its parts:

```tsx
import { Meter } from '@unstyled-solid/base-ui/meter';
<Meter.Root>
  <Meter.Label />
  <Meter.Track>
    <Meter.Indicator />
  </Meter.Track>
  <Meter.Value />
</Meter.Root>;
```
