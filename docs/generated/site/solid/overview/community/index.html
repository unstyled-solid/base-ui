Community

The Base UI ecosystem, support channels, and ways to stay up to date.
View as Markdown

shadcn/ui

shadcn/ui uses upstream React Base UI as its unstyled foundation. If you want Tailwind-styled wrapper components and higher-level APIs without building that layer yourself, you can create a component library with the shadcn/ui create tool.

Styled libraries

Here's a non-exhaustive list of styled libraries built with upstream React Base UI:

  • Kumo: Cloudflare's component library for building modern web applications.
  • coss ui: a modern UI component library. Built by the people behind cal.com.
  • Fragments: a design system platform that includes a component library built on Base UI.
  • Lumi UI: composable React components.
  • Olyx UI: composable components styled with native CSS and HCT color system.
  • ReUI: a large collection of components and templates built on shadcn/ui.
  • FigUI: a Figma UI3 style component library for building Figma plugins.

Unofficial ports

  • base-ui-solid: unofficial port of Base UI to SolidJS.
  • base-ui-vue: unofficial port of Base UI to Vue.
  • radix-ng: unofficial Angular adaptation of Base UI architecture and behavior (originally a Radix UI port).

Get help and contribute

GitHub

Upstream Base UI is an open-source project. If you want to file a bug report or contribute, visit the upstream GitHub.

Discord

For community support, questions, tips, and showcases, join the upstream Discord.

Stay up to date

X

For upstream React releases and announcements, follow @base_ui on X.

Bluesky

Upstream Base UI is also on Bluesky.

GitHub releases

You can also subscribe to the GitHub releases to get notified.

Detailed upstream React release notes are published on the releases page as well.
