Render function

The render prop accepts a live (props, state) callback. Spread props onto the rendered element, including its ref and native event handlers. Read state properties inside JSX so they remain reactive.

Using a function gives you complete control over spreading props and also allows you to render different content based on the component's state.

createRender is the Solid-native setup utility; useRender is its compatibility alias, not a React hook. Supply a live render(props, state) callback and spread props onto the host. Read state properties inside JSX or accessors so updates keep the host, focus and selection stable. Use class, native events and @solidjs/web types. mergeProps reads current handlers at invocation; later handlers run first and may stop earlier Base UI handlers with preventBaseUIHandler(). Explicit undefined masks ordinary defaults. preventDefault(), preventBaseUIHandler() and change-details cancel() are independent operations.

Ref callbacks receive native elements and run untracked without an owner; returned cleanup is ignored. Allocate signals and effects in component setup. A split createEffect(compute, effect) can track an attachment and return cleanup for replacement and disposal. Forward the supplied ref to the actual host; mergeProps does not merge refs. Do not transplant getter descriptors or destructure live props into snapshots.
