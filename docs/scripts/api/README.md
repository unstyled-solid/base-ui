# Solid declaration API extraction

Owner: `docs-api` / `bsolid-docs-api`.

Run from the repository root:

```sh
rtk pnpm docs:api
rtk pnpm docs:api:check
rtk proxy node --test docs/tests/api/api.test.mjs
```

Coordinator script integration: `docs:api` = `node docs/scripts/api/index.mjs`,
`docs:api:check` = `node docs/scripts/api/index.mjs --check`,
`docs:test:api` = `node --test docs/tests/api/api.test.mjs`.
The CLI never builds declarations itself or imports component runtime modules.

## Site contract (schemaVersion 1)

`docs/generated/api/catalog.json` has `sourceSha`, `typescriptVersion`, hashed
declaration `inputs`, and `modules`. A module contains `entrypoint`, `markdown`
(relative sibling filename), and `exports`. Exports contain `name`, `kind`,
`anchor`, `source` (declaration file and line; optional URL), `description`,
`tags`, `type`, `aliasOf`, callable `signatures`, `props`, `properties`,
`inheritedDOM` attribute names, `relatedTypes`, `dataAttributes`, `cssVariables`,
and metadata availability. Row defaults are `documented`, `source` or `unavailable`;
absence never means a fabricated default. Rows include type links to anchors.
Namespace exports and alias spellings receive their own anchors. Anchors encode
the complete public name, so new exports cannot change existing IDs.

`source` defaults carry the local file/line of a literal fallback (and optional
`valueSource` for resolved constants). `parameters` preserves helper signatures;
`props` expands a single local options object, and `returnValue` includes public
return properties. `canonicalAnchor` identifies equivalent object type aliases.
`compatibilityAnchors` / `compatibilityProperties` retain old filtered DOM-row
deep links without displaying DOM implementation details. Markdown aliases link
to canonical tables instead of repeating entire namespaces.

`--check` rejects declaration diagnostics, unresolved exports, unexpected files
and stale generated bytes. `--require-metadata` additionally requires exported
data-attribute and CSS-variable metadata for every component; missing metadata
is an owner request, never borrowed from React. Ordinary checks preserve explicit
unavailable status because many current declarations lack styling metadata.
Fixture tests enforce that strict failure independently of library completion.

## Provenance / adaptation seam

Baseline: Base UI `19511bb171f3b360b006c94cf6d07e53cb446505` (MIT).
Direct renderer-independent reuse: `docs/src/utils/typeOrder.mjs`; description
replacements adapt `docs/next.config.mjs` typesGenerationOptions. Exact ticket
factory, button/accordion type entrypoints, ReferenceTable, CONTRIBUTING namespace
guidance and disabled api-extractor docModel were read as architectural evidence.
The external `@mui/internal-docs-infra@0.13.1-canary.5` pipeline is not installed;
no compatibility with its React classifier is asserted. Extraction and Markdown
serialization here are original Solid-specific implementations using TypeScript
5.9.3, not copied webpack loaders or React reference tables. Markdown uses explicit
stable IDs and ordinary GFM tables rather than depending on upstream renderer IDs.

Source links target actual emitted declarations or explicit local source evidence.
No repository URL is invented for this unpublished workspace. Programmatic
consumers can pass `sourceBase` to `extract` for immutable hosted declaration URLs.
The read-only source enrichment parser associates omitted JSDoc with matching
declarations, follows direct forwarding calls for explicit defaults, and reads
family-local `*DataAttributes`, `*CssVars` / `*CssVariables` declarations even when
not exported from the public barrel. Source modules are never imported/executed.
Only literal/constant fallbacks and explicit boolean/literal state-attribute
conditions are supported; dynamic context fallbacks remain unavailable. Attribute
conditions can supply descriptions with `descriptionSource` provenance when no
JSDoc exists. All read source files are hashed in `inputs`, so source-only changes
also invalidate `--check`. No prose or values are borrowed from React tables.

`report.json` includes both missing styling metadata and missing documentation
with exact source locations. Missing JSDoc prose, CSS-variable descriptions and
undocumented defaults are component-owner requests. Counts include every public
export spelling, including root/subpath aliases.
