# Adapted helper sources

React Base UI is this project's behavioral upstream. `solid-floating-ui` is a
separate source of adapted positioning helpers, not the behavioral upstream.

Its immutable source checkout and revision remain recorded in
`tracking/donors/solid-floating-ui.json` for maintenance. Existing source mappings
are historical migration context, not approval requirements or release gates.

There is no package intake review or donor approval process. Preserve applicable
license texts and attribution when adapting code. The package notice check only
verifies that required texts ship intact, alongside package identity and exports.

React Base UI source comparisons and behavioral tests continue independently.
